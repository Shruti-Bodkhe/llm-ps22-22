# Flashcard Generator (PS22)

Converts pasted study notes into question-and-answer flashcards using Gemini, loads the structured JSON output into a pandas DataFrame, displays interactive cards, and lets users export them as a CSV file.

## Problem Statement
Students need quick revision material. Convert notes into question-and-answer flashcards and export them as CSV.

## How to Run
pip install -r requirements.txt
streamlit run app.py
